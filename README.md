# DoseFlow（药序）

DoseFlow 是一款面向“每天剂量可能不同”场景的 iOS 用药记录应用。它会按照已确认的疗程计划，明确展示昨天、今天和明天该吃什么，并突出今天相较前一天发生的剂量变化，帮助用户减少记错天数、记混剂量和重复服药。

> DoseFlow 只记录和提醒用户已确认的用药计划，不提供诊断、处方或漏服后的剂量建议。处方变化应先由医生或药师确认，再更新到应用中。

## 当前 MVP

- 灵活疗程：可编辑任意药品数量、每次的服药时间、剂量和进餐关系。
- 独立周期：每组安排可选每天、每 2 天、每 3 天等间隔，多种药可各自使用不同周期。
- 剂量循环：在“每 N 天一次”的基础上，可设置第 1 次、第 2 次等不同剂量并循环。
- 引导案例：内置“每天早晚”“每天剂量交替”“每 3 天剂量交替”“多药不同周期”四类案例，并可一键套用。
- 效果预览：编辑过程中实时展示未来 10 天的实际用药结果。
- 精确剂量：使用分数模型保存剂量，避免 `0.5` 等剂量的浮点误差。
- 今日用药：首页可切换昨天、今天、明天，并显示当天药品、剂量、时间和餐前/餐后要求。
- 剂量变化提示：自动对比前一天，突出新增、停用或剂量变化。
- 逐项服药：每种药可单独标记已服用，也可一键完成其余尚未处理的药物。
- 延后提醒：左滑某项药物可设置 1 小时后单独提醒；延后项不会被“一键完成剩余项”误标记。
- 服药记录：支持记为跳过、修正单项状态和撤销当天记录。
- 本地提醒：经用户授权后，按药物分别创建未来 30 天内最近 60 条通知，并在打开 App 时滚动刷新。
- 本地保存：疗程、提醒设置和服药记录保存在设备上，不依赖账户或网络。
- 历史记录：保存服药时的药名、单位和剂量快照，后续修改计划不会篡改旧记录。

## 运行方式

1. 使用 Xcode 打开 `DoseFlow.xcodeproj`。
2. 在 `Signing & Capabilities` 中选择自己的开发团队。
3. 选择 iOS 17 或更高版本的模拟器或真机运行。

本仓库还包含独立的 `DoseFlowCore` Swift Package，可直接运行核心排期测试：

```bash
swift test
```

如果 macOS 当前只选择了 Command Line Tools，可在不修改系统设置的情况下临时指定完整 Xcode：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
```

## 项目结构

```text
DoseFlowApp/
  App/                    应用状态、持久化和通知调度
  Design/                 颜色与通用视觉组件
  Features/Today/         今日用药与剂量变化
  Features/Plan/          疗程查看、灵活周期编辑和效果预览
  Features/History/       服药历史
Sources/DoseFlowCore/     剂量模型、排期引擎和示例疗程
Tests/DoseFlowCoreTests/  核心排期单元测试
```

## 当前边界

- 剂量输入目前以 0.25 个单位为步长，单组间隔可设为 1–30 天。
- 通知按未来 30 天滚动创建；修改计划后会重新生成。
- 暂未接入 HealthKit、iCloud、多设备同步、照护者共享或处方识别。
- App Icon 仍需在发布前补充正式设计稿。

## 下一步建议

1. 增加疗程结束日期、暂停和恢复能力。
2. 增加漏服备注，但不自动给出补服剂量。
3. 增加计划版本历史、医生/药师确认标记及导出分享。
4. 完善无障碍、动态字体、通知动作和真机验收。
